# That_Weather_App - A Simple Weather Application 

This application provides weather forecasts and current weather conditions using a user-friendly interface.

## Features
- Real-time weather updates
- User-friendly interface
- Multi-platform support

## Prerequisites
- Python 3.x
- Flask
- Docker
- Docker Compose

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/That_Weather_App.git
   ```
2. Navigate to the project directory:
   ```bash
   cd That_Weather_App
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python app.py
   ```
